# 市场情绪数据使用报告（交接周杰）

> **阅读对象**：市场情绪 Agent 负责人（周杰）  
> **用途**：将本地已落地的情绪指标喂给 LLM，做上市公司市场情绪风险预警分析  
> **对照文档**：《市场情绪agent实现背景材料 副本.md》  
> **配套代码/数据**：本目录 `IPOI/market/`（含脚本与 `data/` 落盘 CSV）  
> **主交付宽表**：`data/derived/ipo_sentiment_features.csv`（565 家 ×约 62 列）  
> **撰写日期**：2026-08-01（**2026-08-02 更新：已接入马宝灵万得补充包**）  

---

## 1. 你要做什么（一句话）

背景材料约定：

```text
总风险分 = 25% 宏观 + 25% 行业热度 + 25% IPO 市场热度 + 25% 舆情
```

**前三块主链路已明显加强**（万得 HSICS 行业指数、ICE DXY、美债 10Y、网上/网下认购、发行价）；舆情历史仍**不能支撑 2020–2025 回测**，建议 MVP **先砍掉舆情权重或招股书文本代理**（见 §6）。

**评测服务器无外网**：只读 `market/data/`。万得原始在 `dataset/wind/`，已由 `scripts/ingest_wind_exports.py` 清洗进宽表，你一般**不必再跑抓取**。

## 2. 怎么用宽表喂 LLM（推荐接入方式）

### 2.1 入口文件

| 文件 | 说明 |
|------|------|
| `data/derived/ipo_sentiment_features.csv` | 每家 IPO 一行；按 `stock_code`（5 位，如 `02097`）取行 |
| 各列 `.meta.json` sidecar | 同目录/同名，记录来源、抓取时间、日期范围 |
| `data/derived/ipo_events.csv` | 事件级明细（上市日、day1/5/20/60、破发、mdd20） |
| `data/derived/sample_feasible_recommended.csv` | 抽样推荐优先 **49** 家 |
| `data/derived/sample_feasible_companies.csv` | 抽样最大可行 49 家 |

### 2.2 字段分组（给 Prompt 用）

**可用作特征输入（上市前可知）：**

| 模块 | 宽表列 | 背景材料对应 |
|------|--------|--------------|
| 标识 | `stock_code`, `company`, `listing_date`, `industry`, `hsics_l1_name`, `industry_source` | — |
| 宏观走势 | `hsi_ret_*`, `hstech_ret_*` | §1.1（HSI=万得） |
| 宏观流动性 | `mkt_turnover_*`, `southbound_net_*` | §1.2 |
| 宏观波动 | `hsi_vol_20d`, `vhsi_avg_5d` | §1.3 |
| 外部环境 | `dff_*`, `dxy_ret_20d`, **`us10y_level`, `us10y_chg_20d`** | §1.4（DXY=ICE；美债已补） |
| 行业价格 | `ind_ret_*`, `ind_excess_20d`, `industry_return_source`, `hsics_index_code` | §2（**优先 HSICS 官方指数**） |
| 行业资金 | `ind_amount_chg_20d`, `ind_newhigh_ratio`, **`ind_net_inflow_20d`** | §2（净流入约 2022 起） |
| 官方行业指数列 | `hs_sector_index`, `hs_sector_ret_*`, `hs_sector_excess_20d` | 与 HSICS 对齐（同 `ind_ret`） |
| 行业 IPO 热度 | `ind_ipo_count_365d` 等 | §2 |
| 全市场 IPO 热度 | `ipo_count_*`, `avg_*`, `break_rate_60d`, `avg_mdd20_60d` | §3 |
| 认购热情 | `subscription_multiple`, **`public_offer_multiple`**, **`international_placing_multiple`** | §3（公开/网下已齐） |
| 发行价（对照） | `issue_price` | 万得首发价；事件收益仍多用开盘基准 |

**禁止当作预测特征：** `outcome_*`  

**舆情指针（勿当回测证据）：** `news_rows`, `news_earliest`

### 2.3 缺失值约定（Agent 必须遵守）

- **`NaN` = 当时数据不存在或未采集**，**禁止填 0**。
- `industry_return_source`：`hsics`（推荐）或 `concept_basket`（兜底）。
- `ind_net_inflow_20d` 在 2022 前多为 NaN（万得源限制），勿当 0 流入。
- 指数收益 `R_n = P0/Pn - 1`；IPO 窗口收益事件表仍以**首日开盘**为基准，可用 `issue_price` 做敏感性分析。

### 2.4 建议 Prompt 结构（示意）

```text
你是港股 IPO 市场情绪风险分析师。以下为 {company}({stock_code}) 上市日 {listing_date} 前的结构化指标（JSON）。
请分别给出：宏观 / 行业 / IPO市场 三个子风险分（0–100，越高风险越高）及理由；
对值为 null 的字段明确标注「数据缺失，已降权」。
【MVP】不要依赖舆情新闻；舆情子分可固定为中性 50 或整项权重重分配到前三块。
最后按权重合成总分（见背景材料；若砍舆情则前三块各 1/3）。
```

把该行转成 JSON（去掉 `outcome_*`、可选去掉 `news_*`）即可。

## 4. 缺失项、原因、备选与已落地替换策略

### 4.1 总表（万得接入后）

| 指标/模块 | 覆盖情况 | 缺失原因 | 已用替换/处理 |
|-----------|----------|----------|---------------|
| HSI / 成交额 / 南向 / DFF | ≈100% | 极少窗口不足 | HSI=**万得** |
| HSTECH | ~88–99%（视窗口） | 指数 2020-07 发布 | 发布前 NaN→看 HSI |
| VHSI | **73%** | 源约 2021-03 起 | → `hsi_vol_20d` |
| DXY | **100%** | — | **万得 ICE USDX.FX**（已替换 FRED 代理） |
| 美债 10Y | **100%** | — | **万得 `us10y_*`** |
| 行业分类 | 「其他」仅 **29** | 极少数无 HSICS | **HSICS 一级优先** |
| 行业指数收益 `ind_ret_*` | **539（95%）** | 26 家无 HSICS | HSICS 综合行业指数；否则概念篮子 |
| 板块净流入 | **331（59%）** | 2022 前无数据 | `ind_net_inflow_20d`；更早 NaN |
| 认购超额 | **539（95%）** | 26 家致富+万得皆无 | 致富优先 |
| 公开发售 / 国配（网下） | **537 / 520** | 部分老股无字段 | 万得网上/网下倍数 |
| 舆情 | 回测不可用 | 东财仅近期刊 | **建议砍掉**（§6） |
| outcome_* | 98% | 无行情 | 只验证 |

### 4.2 关键口径替换

1. VHSI 缺失 → `hsi_vol_20d`  
2. **行业收益：HSICS 综合行业指数优先**；无则概念篮子（看 `industry_return_source`）  
3. 事件收益/破发：仍多用**首日开盘**；宽表提供 `issue_price` 供你对照  
4. 上市日：EDE，与 EOD 差>30 天回退 EOD  
5. **DXY：万得 ICE**（不再用 FRED 广义美元）  
6. 热度日 = `listing_date - 1`；日历至 2026-06-30

## 6. 舆情模块：建议砍掉或自采（请重点读）

背景材料 §4：独立搜索正负面新闻 → LLM 判方向/相关性/影响（新闻方向 80% + 关注度 20%）。

### 6.1 现状为什么不够用

- 已用 `fetch_news.py` 批量拉了约 **546/565** 家东财个股新闻。  
- 接口**只返回最近约 10～100 条**，语料最早大致到 **2026-01**。  
- 赛题回测主体是 **2020–2025 上市** → 上市日前后的舆情**几乎全空**，宽表里的 `news_earliest` **不能**当「上市前情绪证据」。  
- 评测环境无外网，运行时也无法再搜。

### 6.2 推荐策略（按优先级）

**方案 A — MVP 砍掉舆情（推荐先做）**

- 总分改为：宏观 / 行业 / IPO 热度 **各 1/3**（或保持 25%×3，舆情固定中性 50 并在报告中声明）。  
- Prompt 明确：「本阶段无可靠上市前新闻，不做舆情子分」。  
- 交付叙事写清：结构化三模块已闭环，舆情留二期。

**方案 B — 招股书文本代理（与检索/法务协同）**

- 用风险因素、行业概览等章节做「披露语气/粉饰度/负面陈述密度」代理情绪。  
- 数据来自 `pdf_parsing` / `retrieval`，**不是** `market/news`。  
- 适合回测，且符合「证据可溯源」赛题要求。

**方案 C — 你自行外采历史舆情（工作量大）**

可选方向（均需开发机下载后落盘，评测只读本地）：

| 方向 | 库/站点 | 备注 |
|------|---------|------|
| 港交所/披露易公告与新闻 | https://www.hkexnews.hk/ | 官方，偏公告 |
| 富途/雪球/东方财富历史资讯 | 各站或 AKShare 其它接口 | 需验证是否有**上市日以前**深度 |
| 商业新闻 API | Wind/Choice/Bloomberg | 有历史，需账号 |
| 搜索引擎时间范围抓取 | 需合规与稳定性评估 | 难批量、难复现 |

若做方案 C：建议新建 `data/external/news_hist/{code}.csv`，字段至少 `date, title, summary, source, url`，并按 `listing_date` 过滤上市前 N 天；**不要**继续依赖当前 `stock_news_em` 结果做回测。

### 6.3 现有新闻代码位置（供你改）

- 抓取：`scripts/fetch_news.py`  
- 落盘：`data/external/news/`  
- 宽表只写指针：`build_sentiment_features.py` → `news_rows` / `news_earliest`
