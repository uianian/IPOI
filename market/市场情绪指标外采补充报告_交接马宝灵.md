## 6. 万得导出格式约定（方便工程合并）

1. **编码**：UTF-8 CSV 优先；Excel 亦可。  
2. **日期**：`YYYY-MM-DD` 或 `YYYYMMDD`，在文件头或 README 注明。  
3. **代码**：同时保留 `Wind代码`（如 `2097.HK`）与 `股票代码`（`02097`）。  
4. **每个文件附一行口径说明**：字段定义、单位（亿/百万）、是否复权、时区。
