# 港股IPO招股书 PDF 解析

对应赛题任务1 / 项目模块1（负责人：吴倩倩、likesnow）。目标：把数百页招股书
转成"防幻觉"的结构化知识库，供下游风险抽取（`ipo-risk-feature-extraction`）
和证据检索（`ipo-risk-rag-retrieval`）使用。

## 何时使用

- 拿到一份新的招股书 PDF，需要转成结构化 JSON。
- 已有解析结果，但某几页表格/图表提取错误，需要定位并修复。
- 需要评估解析质量（是否触发容错兜底、哪些页面 category 缺失）。

## 输出 Schema（必须遵守，下游模块依赖此结构）

按页组织的 JSON 数组，每页含若干 layout 元素：

```json
[
  {
    "page": 1,
    "elements": [
      {"bbox": [x1, y1, x2, y2], "category": "...", "text": "..."}
    ]
  }
]
```

10 种 `category`：`text`（正文段落）、`title`（章节/小节标题）、`header`（页眉）、
`footer`（页脚/页码）、`table`（表格，text 为 HTML 表格）、`figure`（图片区域，
text 通常为空）、`table_footnote`（表格脚注）、`table_caption`（表格标题）、
`figure_caption`（图注）、`page_footnote`（页面脚注）。`formula` 在已测试样本
（蜜雪冰城）中未出现，但 schema 需保留该分类以兼容其他招股书。

## 解析流程

1. **模型**：优先使用 Infinity-Parser2（开源多模态文档解析模型，
   `github.com/infly-ai/INF-MLLM`，HF: `infly/Infinity-Parser2-Pro`）。
2. **逐页处理**：OCR → 表格解析 → 页面切片 → 章节识别 → 文字提取。
   已知基线速度约 1min/页（558页约耗时9+小时），若性能是瓶颈，优先考虑：
   - 并发跑多页而非串行；
   - 对 `figure`（无OCR内容）类元素跳过重逻辑处理；
   - 对纯文本页降级用更快的抽取路径，只对含 `table`/复杂版式页用完整多模态解析。
3. **容错兜底**：若某页解析失败，模型可能返回 `bbox: []`，把整页塞进一个
   `text` 元素、内容是未解析的原始 JSON 字符串（参考蜜雪冰城招股书第7页案例）。
   解析完成后必须扫描全量输出，统计 `bbox` 为空的页数占比，作为质量指标之一，
   而不能默默放过。
4. **质量抽检**：解析完一份招股书后，随机抽 5~10 页与原 PDF 视觉比对，
   重点检查下面"已知异常类型"列出的几种情况是否出现。

## 已知异常类型（务必参考，不要重新踩坑）

详见 `references/known_issues.md`，摘要：

| 异常 | 现象 | 应对 |
|---|---|---|
| 竖着的表（旋转表格） | 数据正确率高，但表格结构（行列关系）乱掉 | 解析前检测页面旋转角度，先转正再送入表格解析器；下游使用时对这类表格标记"结构低置信度"，避免直接做数值计算 |
| 截断提取表格 | 长表格跨页时只提取到一部分 | 解析后按 `table_caption` 做跨页表格拼接，或在下游允许"同一表格多个片段"合并 |
| 换行丢失 | 单元格内多行文本被拼成一行，丢失可读结构 | 保留原始 bbox 辅助后续用坐标重新切分行；下游对这类字段做二次正则清洗 |
| 视觉信息丢失 | 加粗/斜体/字体/边框等丢失 | 若下游需要"文本粉饰度"判断（依赖排版强调），需额外记录字体粗细等视觉特征，不能只依赖提取出的纯文本 |
| 正文与表格混淆 | 特定页面（如样本PDF 38~39页）文本和表格识别边界错误 | 人工标注该类页面样例，作为解析后校验规则的输入 |
| chart/图表丢失 | figure 区域 text 为空，图表内数值信息完全丢失 | 对 `figure` 类元素额外跑一次专门的图表理解模型/OCR，或人工补充关键图表数据 |
| 复杂表格提取丢失信息 | 多级表头、合并单元格场景信息丢失 | 优先保证 HTML 表格结构完整性，必要时保留原始表格截图供人工/下游多模态LLM复核 |

## 输出后交给谁

- 结构化 JSON → `ipo-risk-feature-extraction`（做指标与风险特征抽取）
- 结构化 JSON + 页码/bbox → `ipo-risk-rag-retrieval`（做证据定位召回）
