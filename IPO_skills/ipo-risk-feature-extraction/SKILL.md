# IPO 招股书风险特征抽取

对应赛题任务1的第二部分（负责人：马宝灵定义指标标准，吴倩倩负责实现），
以及项目文档中"模块1输出：结构化知识库"部分。

## 输入

`hk-ipo-pdf-parsing` 输出的按页JSON（含 `text`/`table`/`table_caption` 等元素）。

## 输出：结构化知识库字段

```
公司基本信息

财务指标（标准化，多为表格来源）:
- 营收
- 毛利率
- 净利润
- 现金流

风险信息（非标，多为文本来源，需要语义判断）:
- 亏损（是否未盈利、连续亏损年限）
- 关联交易（金额、交易对手、占比）
- 客户集中度（前N大客户占收入比例）
- 供应商依赖（前N大供应商占采购比例）
- 股权安排（特殊股权结构、投票权差异）
- 对赌/赎回条款（触发条件、赎回价格/利率、期限）
```

每条风险信息必须附带来源证据：`{"page": <页码>, "text_span": "<原文切片>"}`，
不允许只给结论不给出处——这是任务1"证据召回率≥85%"指标的基础。

## 抽取方法

1. **表格类指标（营收/毛利率/净利润/现金流）**：优先从 `category=table` 的
   HTML 表格结构化解析，做数值清洗（去除千分位、统一币种单位、区分本年/上年）。
   现金消耗率建议用「经营活动现金流出 / 期末现金及等价物」或「期末现金 / 月均
   现金消耗」等口径，需与马宝灵确认最终公式并在这里固定下来，避免不同人算法不一致。
2. **非标风险特征（对赌条款/关联交易等）**：从 `category=text` 段落做语义抽取，
   建议：
   - 先用关键词/正则做候选段落召回（例如"对赌""回购权""赎回""关联方""集中度"等），
     缩小LLM处理范围；
   - 再用LLM对候选段落做结构化抽取（触发条件、金额、期限等字段），并要求LLM
     同时输出它引用的原文切片（不超过一定长度，避免整段照抄导致后续无法定位）；
   - 对LLM抽取结果做规则校验（如金额字段必须能转成数字、日期字段必须能解析），
     校验失败的样本标记为"待人工复核"而不是丢弃。
3. **"文本粉饰度"识别**：重点关注"风险因素"章节里正面词汇堆砌、模糊表达、
   避重就轻的段落。参考老师指导意见中提到的维度：经营状况描述是否模糊、
   事实描述 vs 主观修饰的比例、是否使用大量限定词/条件句弱化风险表述。
   建议输出一个 0-1 的粉饰度分数 + 命中的具体原文切片，而不是只给一个笼统结论。

## 硬指标自检（每次抽取任务结束前必须核对）

- 关键风险要素抽取准确率 ≥ 80%（对赌/赎回条款、关联交易、客户或供应商集中度、
  现金流消耗压力等）；
- 关键证据片段召回率 ≥ 85%（系统给出的风险结论必须能准确定位到原文支撑段落/表格）。

如果没有标注好的测试集，无法量化这两个指标，应主动提示用户先完成测试集标注
（负责人：马宝灵），而不是跳过校验直接产出结果。

## 港股 vs A股 招股书语言差异（需注意）

港股招股书使用香港法律文书及国际四大会计事务所惯用表述，与A股招股书在
风险披露措辞、条款命名上存在差异（如"对赌"在港股文件中常表述为
"estate/redemption right"相关条款、"业绩承诺"表述方式不同）。抽取规则/关键词库
需要区分港股和A股场景，不能直接套用A股招股书的关键词模板。

  （见 `ipo-multi-agent-orchestration`）
