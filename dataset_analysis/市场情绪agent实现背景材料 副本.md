# 1\.宏观市场分析

|指标|整体市场走势|市场流动性|波动率|外部环境|
|---|---|---|---|---|
|赋值（100/%）|30%|40%|20%|10%|

## 1\.1 整体市场走势

采用恒生指数来表示宏观市场最真实的情况

因为赛题中近些年上市的企业多为AI、医药、科技，所以采用恒生科技指数来反应市场情况也很有必要；

在取得各类指数之后。需要计算出上市日前5日、前20日、前60日的收益率，再用大模型判断分析相关收益率对应的市场环境情况。

（参考）计算上市日前 5/20/60 日收益率 R\_n（建议用交易日数据、以收盘价为准）：

$ R_n = (P_0 / P_n) - 1$

- 记 P\_0为上市日收盘点位，P\_n为上市日前 n 个交易日的收盘点位（n=5,20,60）。

- 注意事项：用「交易日」而非日历日；遇非交易日或涨跌停/停牌要向前回溯到第 n 个有效交易日。

## 1\.2 市场流动性

要描述市场流动性，比较理想的方法是研究港股成交额，采用上市日前20日的港股平均成交额来作为研究市场流动性的主要指标。

同时，南向资金也值得研究，这个南向资金可以用内地用户通过港股通持有港股股票来体现，所以，可以研究上市日前20日港股通资金的变化即南向资金的变化情况来辅助性的描述市场的流动性

## 1\.3 波动率

同样使用恒生指数做参考，用上市日前20日的恒生指数标准差为指标，再使用大模型判断在市场波动率这一部分是否有比较大的影响。

VHSI也是衡量港股市场波动率的一个很好的指数，VHSI是恒指波幅指数，用上市日前5日的平均波幅指数来衡量也可以\~

## 1\.4 外部环境

外部环境主要指的是以美股市场为主的经济变化情况。主要通过以下几个指标来衡量：

找出距上市日最近的美联储货币政策，是加息还是降息，这会对港股市场具有较大的影响。要量化的话最主要的就是找出上市日前20天的美联储基金利率的走势，来判断美联储政策的影响。

同时，相同区间的美债收益率和美元指数也可以用来衡量外部环境的影响。

表格说明：

1\.相对恒生指数超额收益率计算说明：这里的超额收益意为用行业恒生指数收益率减去基准恒生指数收益率得到的差值，该差值可以用来表示相关行业的净热度。

2\.行业指数创新高比例：这里的行业指数创新高比例指的是该行业所有公司中在待分析公司上市日当天是股价为近60日最高的公司所占行业公司数的比例。具体实现方法是：先确定待分析公司所属行业，再根据该行业恒生指数确定成分股，根据各股票交易信息确定有哪些股票在待分析公司挂牌日当天股价为60日中最高。即可确定比例。
