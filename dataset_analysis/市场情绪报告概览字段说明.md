## 二、逐项详解



### 1\. 整体状态（overall\_state）



市场情绪的**\*\*定性状态\*\***，由综合净支持度对 10% 阈值判定。



|状态|中文|判定条件|
|---|---|---|
|supportive|支持因素占优|净支持度 \> \+10%|
|pressured|压制因素占优|净支持度 \< −10%|
|mixed|多空信号交织|净支持度绝对值 ≤ 10%|
|neutral|整体中性|无方向性证据|
|insufficient\_data|数据不足|模块权重总和为 0|



本报告综合净支持度 \+2\.8%，落在 ±10% 区间内，因此判定为 **\*\*多空信号交织（mixed）\*\***。



### 2\. 综合净支持度（overall\_net\_support）



四个模块（宏观市场、行业情绪、IPO市场、公司舆情）各自净支持度的**\*\*有效权重加权\*\***。范围为 −100% \~ \+100%，**\*\*不是 0–100 评分\*\***。



```Plain Text
净支持度 = (支持权重 − 压制权重) / (支持权重 + 压制权重)
```



正值表示多头占优，负值表示空头占优。它衡量**\*\*情绪方向\*\***，不代表风险大小。



### 3\. 市场情绪描述



LLM 生成的一段结论文字。强制要求**\*\*同时保留支持与压制两侧证据\*\***（不能只引用单侧信号），且每条判断须引用真实存在的证据 ID，如 \`\[MACRO\-HSI\-5D\]\`、\`\[IPO\-SUBSCRIPTION\-MULTIPLE\]\`。



### 4\. 最终首日破发风险分（risk\_score）



**\*\*0–100 的风险分\*\***，量化评估"上市首日收盘价低于发行价（破发）"的风险程度。等级阈值如下：



|区间|等级|
|---|---|
|\< 20|very\_low|
|20–39|low|
|40–59|medium|
|60–79|high|
|≥ 80|very\_high|



本报告 60\.0 落入 60–79，等级为 **\*\*high\*\***。



### 5\. 确定性历史校准分（deterministic\_score）



**\*\*不依赖 LLM\*\*** 的确定性评分（rules floor），由 HistoricalMarketRiskScorer 计算：各指标对历史样本做**\*\*时点百分位\*\***与**\*\*同期趋势\*\***加权。



```Plain Text
percentile = (lower + 0.5 × equal) / n
trend = 50 + 50 × tanh(Δ / scale)，scale = MAD × 1.4826
```



它作为评分的**\*\*底线\*\***，防止最终分过度偏离确定性结论。



### 6\. LLM 独立风险分（llm\_score）



LLM 通过 ReAct 循环（market\_react）取得证据账本后给出的**\*\*独立评分\*\***。该分必须通过**\*\*证据校验\*\***：LLM 若引用了不存在的证据 ID，其评分会被拒绝。本报告 LLM 引用了 \`OPINION\-001 / OPINION\-002 / OPINION\-003 / OPINION\-006\` 等真实证据，校验通过。



### 7\. 合并方法（score\_reconciliation）



展示确定性分与 LLM 分如何合并为最终分：



|项目|值|
|---|---|
|确定性底线|55\.5|
|LLM 分|60\.0|
|差值|4\.5|
|合并方法|max\_llm\_and\_rules\_floor|
|决策|LLM 识别到更高且有证据支持的风险，采用 LLM 分|



即最终分 = max\(确定性底线, LLM 分\)。策略上偏向**\*\*宁可高估、不可低估\*\***。



### 8\. 主要风险锚点：发行价



判定破发的**\*\*核心业务定义\*\***：首日收盘价低于发行价（below\_issue\_price）即视为破发。该锚点同时是上市后评分的主要指标。



### 9\. 二级市场收益基准：上市首日开盘价



累计收益、回撤等**\*\*上市后指标\*\***以**\*\*首日开盘价\*\***为基期计算（而非发行价）。两个锚点用途不同：破发看发行价，收益基准看首日开盘价。



### 10\. 评分版本（score\_version）



评分逻辑的版本号（historical\-v1），取自 `market/configs/historical_scoring.yaml`，用于追溯评分口径的变更。



### 11\. 历史数据截止（as\_of\_date）



分析截止日 = 上市日（2025\-12\-23）前一日（2025\-12\-22）。所有指标按**\*\*时点（point\-in\-time）\*\***取值，杜绝使用未来数据。



### 12\. 发行价锚点（issue\_price 可用性）



标记发行价数据是否可得。本报告为 available；若不可得，破发锚点会被降级处理（如上市后评分中该指标将被剔除）。



## 三、两套量纲：情绪方向 vs 风险大小



概览中并存两套量纲，解读时需区分：



|体系|字段|范围|含义|
|---|---|---|---|
|情绪体系|综合净支持度|−100% \~ \+100%|方向：多头多还是空头多|
|风险体系|首日破发风险分|0–100|大小：破发风险有多高|



本报告 \+2\.8% 净支持（几乎均衡）与 60\.0 高风险分（偏高）并不矛盾：前者反映市场信号的多空对比，后者是综合四模块后的风险量化。



## 四、相关区块口径



### 数据边界



列出上市日期、分析截止日、最近市场观察日、特征文件、新闻文件等数据来源与时点信息，用于审计每次分析所用的数据是否时点一致。



### 分模块结论



四个模块（宏观市场、行业情绪、IPO市场、公司舆情）各自的状态、净支持度、数据覆盖率与证据驱动的结论。有合格舆情时四模块各占 25% 权重；无舆情时宏观、行业、IPO市场各占 1/3。



### 权重口径声明



- 有通过时间与相关性校验的舆情时，四模块各 25%。

- 无可靠舆情时，宏观、行业、IPO市场各 1/3，舆情不参与。

- 宏观内部按走势 30%、流动性 40%、波动率 20%、外部环境 10% 加权；其余模块按有效方向性证据等权。

- 净支持度绝对值不超过 10% 时标记为多空交织。
